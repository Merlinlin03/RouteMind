# RouteMind 设计决策

- 基座：Qwen3-32B，采用 QLoRA；本次交付 Python 工程，不执行真实训练。
- 消费方：OpsPilot、GrowthTriage。本次仅交付客户端、适配与契约测试，不修改消费项目。
- 模型职责：多语言反馈、多意图/条件诉求、上下文、槽位/证据、情绪、明确人工诉求及细粒度广告体验理解。
- 模型不输出执行命令或流程节点；TurnPlanner、Flow YAML 和 Workflow 保留业务决策职责。
- 服务只提供真实模型推理后端；不可用时显式报错。测试替身只位于 tests 目录。
- 数据：六语言合成种子、生成/校验/分组切分流程；保持来源和审核状态可追溯。
- 训练：只监督答案 token，训练/推理模板一致；验证集与独立测试集分离。
- 评估：无效/缺失输出计入失败，保留原始预测和错误样本。
- 发布目标：Merlinlin03/RouteMind 私有仓库，不包含密钥、权重或训练输出。

## 后续验证

真实 CUDA 训练与推理、数据人工审核、正式独立测试集效果和消费项目端到端联调，在相应环境完成后记录。
